# Todoeléctrico · Propuesta de diseño

Prototipo estático del rediseño de la tienda Todoeléctrico: 26 pantallas de escritorio y móvil con productos, precios y opiniones reales del catálogo. Los enlaces funcionan, así que se puede recorrer como una tienda publicada.

**Ver el prototipo:** https://iamshoaibktk.github.io/todoelectrico-diseno/

- `index.html`: todas las pantallas y el recorrido de compra.
- `movil.html`: las pantallas de móvil dentro de un teléfono.
- `m/`: las pantallas de móvil a pantalla completa.
